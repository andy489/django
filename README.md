# Django

Learning material for the **Django 6: The Big Picture** course by Reindert-Jan Ekker.

Covers Django 4.x / 5.x / 6.x with Python 3.10+.

## Modules

| # | Module | Contents |
|---|---|---|
| 01 | [Django Big Picture](01-django-big-picture/) | Intro, application structure, choosing Django — notebook + travel blog demo |

## Prerequisites

- Python basics (functions, classes, modules)
- HTML basics
- Database basics (tables, rows, SQL)

## Setup

```bash
python -m venv .venv
source .venv/bin/activate
pip install django pillow
```
