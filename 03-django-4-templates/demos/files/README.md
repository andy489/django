# Django 4 Templates

## The exercise files :
Each exercise folder corresponds to a module in the course. For each module, there is a `starter` folder that contains the initial code and a `final` folder that holds the final state.

The demo assets are available in the `ressources` folder


[IMAGE]

## Installation :

### Install Django new version

$ python -m pip install -U Django

### verify version installed

$ django-admin --version


## To use these exercise files :

### activate a virtual environment (recommanded)
$ cd dailynews
$ python -m venv env
$ source env/bin/activate

### install the required package

$ pip install -r requirements.txt

## To start the project

### on Mac
$ python3 manage.py runserver

### on Windows
$ python manage.py runserver
